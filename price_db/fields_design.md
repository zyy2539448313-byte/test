# 价格数据库 v0 —— 字段设计与使用说明

配套《执行手册_工具与30天节奏》交付物 ②。目标：**先别写代码**，用飞书多维表格当免费后台，三人（你 + 合伙人 C + 校准师傅）都能直接在表里打字。

## 文件清单

| 文件 | 用途 |
|---|---|
| `fields_design.md` | 本文件：字段字典 + 建表步骤 + 校准流程 |
| `防水补漏.csv` | 防水品类模板（含示例数据，导入即建表） |
| `管道疏通.csv` | 疏通品类模板 |
| `空调维修.csv` | 空调品类模板 |

## 导入飞书多维表格（3 分钟）

1. 飞书 → 云文档 → 新建「多维表格」；
2. 右上角「导入」→ 选 CSV → 选这三个文件（一个 CSV 一张数据表，放在同一个多维表格里）；
3. 导入后把下列字段的类型改为对应类型（CSV 导入默认都是文本）：

| 字段 | 改成 | 说明 |
|---|---|---|
| 合理价下限 / 合理价上限 / 实收价 | 数字（¥） | 之后可做公式和图表 |
| 发生时间 | 日期 | |
| 城市 / 品类 / 子项目 | 单选 | 方便筛选透视 |
| 套路标签 / 数据来源 | 多选 | 一条数据可打多个标 |
| 师傅已校准 | 复选框 | 勾上 = 有师傅背书 |
| 置信度 | 单选（高/中/低） | |

## 字段字典

### A. 定价基准字段（这是表的骨架，用来生成「速查工具」的合理价区间）

| 字段 | 说明 |
|---|---|
| 品类 | 防水补漏 / 管道疏通 / 空调维修（后续扩：开锁、家电清洗…） |
| 子项目 | 具体维修项，如「马桶疏通」「空调加氟」 |
| 计价方式 | 按次 / 按米 / 按平方 / 按公斤 / 按压力表读数 / 按台——**刺客套路的核心就是计价方式被偷换** |
| 合理价下限 | 市场正常区间下限（师傅校准后填） |
| 合理价上限 | 市场正常区间上限 |
| 城市基准 | 该价格适用的城市/区域（默认全国一线均值，本地差异备注） |
| 师傅已校准 | 有真实师傅确认过的价格才勾 |

### B. 投诉/实收样本字段（喂给库的原始数据，来自爬虫 + 线下收集）

| 字段 | 说明 |
|---|---|
| 实收价 | 消费者实际被收的钱 |
| 计价过程 | 关键！比如「报价 30 元/斤，注胶 38 斤收 1140」 |
| 套路标签 | 按斤收费 / 低价引流上门加价 / 高空作业费 / 偷换计量单位 / 只换不修 / 检测费刺客 / 无报价先施工… |
| 涉诉金额 | 对方诉求退回的金额 |
| 数据来源 | 黑猫投诉 / 师傅访谈 / 平台截图 / 评论区收集 / 新闻报道 |
| 来源链接 | 黑猫投诉单链接（爬虫 details.jsonl 的 url 字段直接搬） |
| 发生时间 | 投诉/服务发生时间 |
| 商家/平台 | 如「啄木鸟」「某同城平台接单人」 |

### C. 运营字段

| 字段 | 说明 |
|---|---|
| 置信度 | 高=师傅确认或多个来源交叉；中=单一来源；低=待核实 |
| 可用于内容 | 勾上 = 这条可以做短视频选题（细节完整、有冲击力） |
| 备注 | 师傅原话、争议点、下次要问什么 |

## 数据怎么流进来（分工）

1. **爬虫（已交付①）**：`data/details.jsonl` 里的涉诉金额、投诉问题字段 → 挑维修类的复制进 B 区字段（第 1 周你做，第 2 周起每周日花 30 分钟）；
2. **师傅校准**：每次视频通话 30 分钟，师傅看 A 区字段直接说「低了/高了/差不多」→ 改数字 + 勾「师傅已校准」+ 备注写师傅原话；
3. **合伙人 C**：线下收集的真实报价单拍照 → 手动录入 B 区；
4. **每周日经营会**：按品类透视「套路标签 × 实收价」，看哪个子项目价差最大 → 那就是下周内容选题和速查工具优先覆盖的项。

## 示例数据说明

三个 CSV 各带 6-8 行**示例行**（按真实套路模式虚构，城市用通用值），用途是让导入后立刻看到表该长什么样、筛选项能选出来。**示例行城市列都写着「示例」，正式使用前删掉即可。** 真实数据进来后按置信度管理。
